# Undangan Dimas & Laras

Undangan nikah interaktif bergaya game. Satu file, tanpa build.

## Pasang di GitHub Pages
1. Buat repo baru di GitHub (misalnya `undangan`).
2. Upload `index.html` dan `README.md` (Add file > Upload files).
3. Settings > Pages > Source: Deploy from a branch > `main` / root > Save.
4. Tunggu 1-2 menit, link: `https://USERNAME.github.io/undangan/`

## Ganti isi
Edit `index.html`: nama, tanggal, jadwal, dan teks surat.
